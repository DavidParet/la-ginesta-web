# La Ginesta Web

Premium digital guide for La Ginesta camper van — a responsive, modern web experience for guests.

---

## Overview

This project transforms Notion content into a polished, mobile-first website that serves as the complete onboarding and in-stay guide for La Ginesta guests. It combines clarity, warmth, and premium UX into a single, self-contained digital experience.

## Features

- **Guides** — Step-by-step instructions for all van systems and appliances
- **QR System** — Physical QR codes linking guests directly to relevant sections
- **Videos** — Embedded walkthroughs for key setup and usage moments
- **Onboarding Experience** — A smooth, welcoming flow from arrival to departure
- **Responsive Design** — Built mobile-first, optimised for any device

## Stack

| Layer | Technology |
|---|---|
| Structure | HTML |
| Styling | CSS |
| Interactivity | JavaScript |
| Hosting | Vercel |

## Design Principles

- Mobile-first and touch-friendly
- Minimal, uncluttered layouts
- Clear hierarchy and fast navigation
- Premium feel without unnecessary complexity

## Project Structure

```
assets/          Static assets (images, icons, logo, mockups)
docs/            Documentation, guides, prompts and planning
videos/          Video content for embedded guides
qr/              QR code assets and configuration
```
